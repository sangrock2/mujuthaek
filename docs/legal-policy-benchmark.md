## 우선 보강할 적용안

1. **권리 행사 방법을 행동 단위로 안내한다.** 계정 설정에서 탈퇴하는 경로, 브라우저 저장 데이터 삭제, 이메일로 열람·삭제를 요청하는 방법을 구분한다. 요청 유형과 대상 계정을 확인할 최소 정보만 받으며 신분증·주민등록번호를 일괄 요구하지 않는다. 처리 기한을 새로 약속하려면 요청 유형별 법정 기한과 실제 응대 체계를 확인한다.
2. **개정 공지와 과거 본문을 보존한다.** 현재 v1.0을 보존하고 이후 버전에는 공고일·시행일·변경 이유·항목별 전후 비교를 둔다. 서비스 릴리스 롤백 기록과 법적 문서 이력은 별도다. 최초 버전에 존재하지 않는 이전 버전을 만들지 않는다.
3. **회원 통지 수단을 구체화한다.** 일반 공지와 개인별 중요 통지를 구분하고, 계정별 알림함 등 실제 동작하는 경로를 확인해 연결한다. 이메일·푸시가 비활성인 현재 상태를 전제로 수단과 실패 시 대응을 정한다.
4. **국외 처리 정보를 운영 증빙으로 보완한다.** Vercel의 현재 하위처리자·국가·보관 범위·연락처와 Gmail 문의 처리를 확인한다. 다른 사이트의 수탁자 목록이나 동의 문구를 복사해 이 항목을 채우지 않는다.
5. **보유기간과 실제 삭제를 맞춘다.** S3의 30일 만료와 달리 자동 만료가 없는 로컬 사본·용량 순환 진단 로그는 실제 정책·정리 작업부터 정한다. 문구만 바꿔 자동 삭제된다고 주장하지 않는다.
