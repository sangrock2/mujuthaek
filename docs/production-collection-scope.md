# 운영 수집 범위

2026-11-14 사용자 결정: LH만 우선 운영하는 축소안 대신, 현재 구현한 전체 수집 범위를 운영 대상으로 유지한다. 이 문서는 범위 결정이며 실행·활용 승인·인증키 등록 또는 유료 AI 사용 승인을 뜻하지 않는다.

## 기존 입지 데이터 범위

공고 출처와 별도로 기존 area 원천 9종(지하철역, 버스정류장, 학교, 공원, 병원, 시군구 경계, 읍면동 경계, 상권·상가정보, 도로명주소 출입구)도 대상에 유지한다. 이 데이터는 파일 확보·변환·적재 절차이며 공고 스케줄러만 켠다고 모두 갱신되지는 않는다. 대용량 적재 시 4GB 서버의 메모리를 별도로 측정한다.

## 활성화 전 준비

- `LH_API_KEY`: LH 목록·상세·공급 및 마이홈 API 각각 활용신청.
- `DATA_GO_KR_SERVICE_KEY`: 보조금24·복지로 중앙·지자체·K-Startup 각각 활용신청.
- `YOUTHCENTER_API_KEY`: 온통청년 인증키.
- `BIZINFO_API_KEY`: 기업마당 인증키.
- 분석 모델 연결·예산·발송 또는 외부 추적 설정은 별도 확인한다. 실제 비밀값은 저장소·문서·채팅에 남기지 않는다.

활성화 작업에서는 서버 전달 환경변수, DB `sources.enabled`, 출처별 권한·응답, 원문 다운로드 조건, 실패·재시도, 전체 처리 메모리를 점검한다. 과거 팀 프로젝트의 키나 수집 예외 승인으로 개인 운영의 권한을 대신하지 않는다.

## 처리량·비용

전체 출처를 포함하는 것과 모든 과거 공고를 즉시 유료 분석하는 것은 별개다. 전체 출처를 순차 처리하되 신규·변경 공고를 구분하고, 최초 적재 범위·묶음별 최초 선별·대기열·건당/일/월 분석 예산을 운영 정책으로 정한다. 기존 초기 intake 설정은 전체 누적 분석 비용 상한이 아니다.

사용자 확정: AI 월 $10, 평일 09~19시 매시간, 현재 모집 중·접수 예정·상시모집 전체, 초기 표본 확인 후 검증된 정보를 자동 공개한다. 부분 통과 공고는 검수 항목을 확정 정보에서 제외하고 나머지를 게시하며 해당 항목의 검수를 남긴다. 공고 전체 검수(IN_REVIEW)는 승인 전까지 공개하지 않는다. 운영 설정은 일 $1·원본 버전당 $0.50도 적용하고, 동시 처리를 1개로 제한한다. 첫 단계의 `manual` 모드에서는 발행 이벤트를 보류하며 사용자 표본 확인 후에만 `verified`로 전환한다.

키는 개인 계정의 `.env.collection`을 사용하고 Git·빌드 컨텍스트·로그에서 제외한다. 운영 활성화 절차는 개인 배포 README의 수집·분석 항목을 따른다. API 키가 준비됐다는 사실만으로 워커가 이미 실행 중이라고 안내하지 않으며, 입지 파일 적재는 별도로 확인한다.
