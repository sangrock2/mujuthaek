# 호별 목록이 없는 공고의 지도

143개 위치의 좌표 복구와 공개 API 반영을 확인한 뒤 운영 브라우저에서 추가 표시 문제를 발견했다. 단지 좌표가 있어도 hasUnits=false이거나 호별 목록 조회가 비어 있으면 PC·모바일 상세 화면이 지도 블록 전체를 렌더링하지 않았다. 지도 키·좌표 응답과 별개의 화면 조건 문제다.

공통 NoticeLocationSection으로 확인된 단지 위치를 호별 목록과 독립적으로 표시한다. 호별 목록이 있으면 기존 선택한 집과 연결된 지도 동작을 유지하며, 목록이 없거나 아직 불러오는 중이면 위치 전용 블록을 표시한다. 확인된 좌표가 없으면 가짜 핀이나 주택 정보를 만들지 않는다.

관련 파일만 Prettier·ESLint·TypeScript로 확인하고, 합성 공고에서 hasUnits=false 및 빈 호별 목록 두 경우를 브라우저 회귀 검사로 추가한다. E2E에는 공급자 키를 주지 않고 화면 연결만 검증하며 실제 카카오 타일은 운영 PC·모바일에서 별도로 확인한다. API·DB 스키마·운영 예산·키를 변경하지 않는 프론트 수정이다.
