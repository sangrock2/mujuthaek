# OpenAI 잔액·지출 한도 오류의 즉시 재시도 중단

잘못된 첨부를 제외한 재추출 5건을 건당 $0.50, 총 $2.50 및 기존 일·월 상한 안에서 수동 공개 모드로 시도했다. 다섯 요청 모두 `credit_balance_exhausted`로 실패했고 새 후보와 공개 결과는 생성되지 않았다. 기존 반려 기록은 보존했다. 이 운영자 실행에서 만든 새 이벤트 5개만 처리 완료 표시에 등록해 자동 재처리를 차단했다. 실패 기록을 삭제하거나 성공으로 바꾸지 않았다.

OpenAI 공식 오류 문서에서 이 코드는 조직의 선불 크레딧 잔액 부족을 뜻한다. 기존 연결부는 스트림 실패를 모두 일시 장애로, HTTP 429를 모두 속도 제한으로 취급해 즉시 재시도했다. 알려진 잔액·조직·프로젝트 지출 한도·결제 비활성화 코드는 즉시 재시도하지 않도록 분류한다. 일반 속도 제한·서버 오류·연결 단절의 재시도는 유지한다.

사용량을 받지 못한 스트림 실패의 `maybe_billed=True`는 유지한다. 장부의 $0.6483은 기존 코드가 보수적으로 계산한 추정치이며 실제 청구 확정액이 아니다. 제공자의 실제 사용량·청구서를 확인하지 않고 과거 비용 기록을 0으로 변경하지 않는다. 이 수정은 크레딧 충전이나 워커의 전체 재처리 정책 변경을 대신하지 않는다.

변경 연결부의 잔액 오류·일반 429·서버 오류·스트림 단절을 가짜 HTTP/SSE 응답으로 검사했다(11건 통과, 나머지 21건 미실행). 실제 키·네트워크·유료 API 호출은 사용하지 않았다.
