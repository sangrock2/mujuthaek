# 검수 목록의 조회 실패와 실제 0건 구분

운영 검수 중 API 조회가 실패했는데 화면이 `대기열 0건`과 `검수할 항목이 없어요`로 표시되는 문제를 확인했다. 첫 조회의 로딩·실패·정상 빈 결과를 구분하고, 조회 실패 안내와 수동 재시도 버튼을 추가했다. 기존 페이지가 있으면 확인된 건수와 항목을 유지한다.

추가 페이지 조회 실패 뒤에는 화면 끝 감지가 같은 요청을 계속 반복하지 않는다. 재시도 버튼은 실패한 다음 페이지만 다시 받아 이미 읽은 페이지를 모두 조회하지 않는다. 검수 승인·반려 API와 권한 검사는 변경하지 않았다.

변경 파일의 형식·ESLint·TypeScript 검사를 통과했다. 실제 브라우저에서 합성 관리자 응답만 사용해 초기 503 후 수동 복구, 정상 0건, 추가 페이지 실패 후 기존 데이터 유지와 해당 페이지만 재시도하는 세 흐름을 PC·모바일에서 검사했다. 운영 관리자 자격증명·실제 검수 데이터·Docker·백엔드 서버를 사용하지 않았다. 처음 검사에서 발견한 다음 페이지 자동 반복을 보완한 뒤 해당 두 브라우저 검사를 다시 통과했다.
